# Skill: create-angular-page

## Frontend Rules
- Angular (the project's pinned version — see the stack conventions' version policy), standalone components.
- Signals for local component state.
- Typed API services that go through `ApiService`.
- Syncfusion components (`@syncfusion/ej2-angular-*`) where useful.
- Mobile-first responsive layout.
- Place the page under `features/<area>/<domain>/pages/` (areas in `project-description.md`).
- UI copy language, currency and date formats as defined in `project-description.md`.
- Show amounts returned by the API; never compute the charged total in the page.
- Accessibility attributes.
- Loading, empty and error states.
- Keep components focused and readable.

## Page Creation Steps
1. Define user goal.
2. Define screen flow.
3. Define route.
4. Define component tree.
5. Define API dependencies.
6. Define state model.
7. Implement page.
8. Add tests where applicable.
9. Update UI docs.

## Output
- Route
- Component list
- State design
- API integration
- Validation
- Error handling
- Responsive behavior
- Accessibility notes
