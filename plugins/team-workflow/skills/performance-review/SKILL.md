# Skill: performance-review

## Backend Review
- N+1 queries
- Missing indexes
- Inefficient pagination
- Large payloads
- Slow reports
- Unnecessary tracking queries
- Caching opportunities

## Frontend Review
- Large components
- Unnecessary re-renders
- Inefficient change detection
- Large bundles
- Missing lazy loading
- Slow forms or tables
- Missing loading states

## Output
1. Performance risks
2. Evidence or likely cause
3. Severity
4. Recommended fix
5. Validation method
