# Skill: bug-fix

## Workflow
1. Reproduce or understand the issue.
2. Identify expected behavior.
3. Identify actual behavior.
4. Locate root cause.
5. Make the smallest safe fix.
6. Add or update tests.
7. Run relevant tests.
8. Update documentation if behavior changed.

## Rules
- Do not rewrite unrelated code.
- Do not add unrelated features.
- Do not mask the problem.
- Fix root cause, not symptoms.
- Add regression tests.

## Output
1. Bug summary
2. Root cause
3. Fix applied
4. Tests added
5. Validation steps
6. Risk assessment
